# Local ticket setup

Local Markdown is used for each developer's decomposition of work. The decisions are already made
in [the template](template.md): local tickets, default triage labels, multiple domain contexts,
and project `wiki/adr/`. This is not an interactive setup wizard.

When a project's `.scratch/AGENTS.md` is absent, copy [the template](template.md) there from the
workspace root. Leave existing instructions untouched. Developers can then adapt their local copy;
template updates do not replace local choices. Keep the template tracked and all generated files
gitignored.
